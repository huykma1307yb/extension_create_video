# Tạo video AI

Extension Chrome tạo kịch bản, prompt ảnh (ChatGPT) và prompt Veo 3, rồi tự thao tác trên Google Flow để tạo 5 video bán hàng (9:16, mỗi cảnh 8 giây).

## Cài đặt
1. Tải repo về, vào `chrome://extensions`, bật **Developer mode**.
2. Bấm **Load unpacked** và chọn thư mục repo.

## Cách dùng
1. Nhập **Thông tin sản phẩm**: prompt tự tạo.
2. Trên ChatGPT: tạo ảnh 360° (Prompt 360°), rồi 5 ảnh cảnh (Ảnh cảnh 1–5), lưu tên `canh1`…`canh5`.
3. Chọn 5 ảnh trong panel, mở dự án Google Flow, bấm **② Tạo 5 video trên Flow**.
4. Chờ Flow render xong rồi tải video về.

> Phần tự thao tác trên Flow dựa trên giao diện hiện tại của Flow và có thể cần chỉnh khi Flow đổi giao diện.
